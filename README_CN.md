# Pocket Audio

[English](README.md)

**Pocket Audio** 是一个面向 **Game Boy Advance** 的浏览器音乐 ROM 制作器与播放器。

你可以在浏览器中导入音乐、编辑歌曲信息、添加封面和同步歌词、预览最终 GBA 界面，并直接生成可以在模拟器或真机上运行的 `.gba` ROM。

> 当前开发线：**Pocket Audio Builder 0.16.x**  
> 当前已记录的最新 Builder：**0.16.2**

## 已经实现的功能

### 浏览器 ROM 制作器

Pocket Audio 当前可以作为一个独立的浏览器工具运行，已经支持：

- 导入多首歌曲。
- 在浏览器支持的情况下读取 MP3、WAV、OGG、FLAC、M4A/AAC 等常见音频格式。
- 从支持的文件中读取歌曲元数据和内嵌封面。
- 编辑歌名与歌手信息。
- 添加、更换或移除封面。
- 调整歌曲顺序、删除歌曲。
- 估算单曲和最终 ROM 所占空间。
- 直接在浏览器中生成独立 `.gba` 文件。

当前 ROM Builder 会遵守标准 GBA 的 **32 MiB ROM 上限**，当项目超出容量时会直接提示。

### 尽量与 ROM 一致的播放器预览

编辑器中内置了一个 **240×160** 的播放器预览，它的目标不是做普通网页播放器，而是尽量还原最终生成 ROM 的实际行为。

目前预览已经包括：

- 播放 / 暂停。
- 上一首 / 下一首。
- 前后 ±5 秒跳转。
- 歌词界面。
- 播放模式切换。
- 切歌过渡动画。
- 歌名与歌手滚动显示。
- 根据封面生成的模糊背景。

让浏览器预览和真正 ROM 的画面、动画与逻辑尽量保持一致，是 Pocket Audio 的核心目标之一。

### 同步歌词

Pocket Audio 已经可以把同步歌词真正打包进生成的 ROM。

当前支持：

- `.lrc`
- `.srt`
- `.txt`

Builder 会提前把歌词处理成适合 GBA 使用的数据，ROM 端拥有独立歌词界面，并根据当前播放进度自动跟随歌词。

### 多曲播放

多曲 ROM 当前支持三种播放模式：

- 列表循环。
- 单曲循环。
- 随机播放。

在 GBA 中通过 `SELECT` 切换。

如果 ROM 里只有一首歌，Pocket Audio 会主动移除没有意义的模式逻辑：不显示播放模式图标，`SELECT` 不响应模式切换，歌曲播放结束后直接停止/暂停。

### 可调输出音质

Builder 当前提供三档 GBA PCM 输出设置：

| 设置 | 用途 |
| --- | --- |
| 11 kHz | 更节省 ROM 空间 |
| 16 kHz | 推荐的平衡档 |
| 22 kHz | 更高音质 |

生成的播放器使用 **GBA Direct Sound PCM** 播放音频。

### 真机测试

Pocket Audio 不只是模拟器里的概念验证。开发版本已经通过烧录卡在真实 Game Boy Advance 上进行测试，包括音乐播放、封面显示、UI 动画以及同步歌词。

## 当前按键

| 按键 | 功能 |
| --- | --- |
| `A` | 播放 / 暂停 |
| `B` | 打开 / 返回歌词界面 |
| `Left / Right` | 后退 / 前进 |
| `L / R` | 上一首 / 下一首 |
| `SELECT` | 多曲 ROM 中切换播放模式 |

项目仍在开发中，因此按键设计未来仍可能调整。

## Pocket Audio 的工作方式

Pocket Audio **不会尝试让 GBA 在运行时直接解码现代桌面音频格式**。

相反，耗时的工作会由浏览器 Builder 提前完成：

1. 导入并解码源音频。
2. 读取元数据和封面。
3. 预处理封面、背景和文字资源。
4. 解析并预处理同步歌词。
5. 转换成适合 GBA 的 PCM 数据。
6. 将歌曲和资源打包进播放器 ROM。
7. 输出可以直接运行的 `.gba` 文件。

这样既能让用户直接从常见音乐文件开始，又能让 GBA 端保持足够简单、稳定和可预测。

## 当前开发重点

### 近期

- 修掉歌词动画剩余的一点闪烁和快速滚动边缘问题。
- 继续让 Builder 预览和 ROM 实际表现保持一致。
- 提升真机播放与过渡动画稳定性。
- 使用更多歌曲、不同歌词密度和不同 ROM 容量继续测试。
- 继续优化音质与 ROM 体积之间的平衡。
- 清理开发文件，准备第一个真正可公开的源码包。
- 补齐可复现的构建说明和示例工程。

### 之后

- 更高效的音频存储方式，让同一 ROM 能放更多歌曲或更高音质。
- 更完整的项目保存 / 读取流程。
- 在不明显增加 GBA 运行负担的前提下提供更多自定义能力。
- 扩大烧录卡和模拟器兼容性测试。

## 项目状态

Pocket Audio 正在持续开发，目前已经能够生成可用的 GBA 音乐播放器 ROM，但**还不视为稳定正式版**。

等当前 Builder 和 ROM Runtime 完成整理、文档与可复现测试后，再发布第一个正式公开源码版本。
